# Evidencia fotográfica — Semana 12

Guarda aquí las capturas de la ejecución real en un teléfono. No se incluyen imágenes inventadas.

| Archivo sugerido | Qué debe mostrar | Cuándo tomarla |
| --- | --- | --- |
| `01-permiso-camara.png` | Diálogo del sistema pidiendo permiso de cámara | Primera vez que el bibliotecario pulsa **Tomar foto** |
| `02-permiso-denegado.png` | Alerta explicativa y el botón **Elegir de la galería** disponible | Después de rechazar el permiso |
| `03-camara.png` | Vista de la cámara abierta | Al conceder el permiso |
| `04-portada-detalle.png` | Portada nueva en el detalle del libro | Después de subir la foto |
| `05-portada-lista.png` | Miniatura de la portada en el catálogo | Al volver a **Catálogo** |
| `06-sin-conexion.png` | Mensaje **Necesitas conexión para subir la portada.** | Con modo avión, pulsando **Tomar foto** |
| `07-estudiante.png` | Detalle sin el bloque **Portada del libro** | Sesión iniciada como estudiante |
| `08-actividad.png` | **Perfil → Actividad reciente** con eventos `cover.*` | Después de subir una portada |
| `09-flujo.mp4` (opcional) | Flujo completo: permiso → cámara → subida → portada visible | Video corto de la demostración |

Consejos:

- Usa un teléfono real; el simulador de iOS no tiene cámara.
- No incluyas datos personales, correos ni tokens en las capturas.
- Si una captura muestra el correo de la cuenta, puedes taparlo antes de subirla.
- Enlaza las capturas desde `PRUEBAS_MANUALES.md` §4 o desde `SERVICIO_FOTOS.md` §8.
